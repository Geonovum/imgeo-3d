## Ideeën van Blender

Blender: 

**BSDF**, **BSDF**

| Attribuut  | Betekenis |
|------------|-----------|
| Base Color | Basiskleur van het materiaal |
| Roughness  | Mate van microscopische ruwheid |
| Metallic   | Mate waarin het materiaal zich als metaal gedraagt |
| IOR        | Brekingsindex |
| Alpha      | Ondoorzichtigheid/transparantie |
| Normal     | Oppervlaknormalen voor de lichtberekening |
| Weight     | Gewicht van een materiaallaag, waar van toepassing |
| Subsurface Weight | Bijdrage van onderhuidse lichtverstrooiing |
| Subsurface Radius | Schaal van de verstrooiing per kleurkanaal |
| Subsurface IOR | Brekingsindex voor subsurface scattering |
| Subsurface Anisotropy | Richtingsafhankelijkheid van de verstrooiing | 
| Specular IOR Level | Aanpassing van de intensiteit van de speculaire reflectie |
| Specular Tint | Kleurbeïnvloeding van de speculaire reflectie |
| Anisotropic | Richtingsafhankelijkheid van reflecties |
| Anisotropic Rotation | Draaiing van de anisotrope richting |
| Tangent | Richting voor anisotrope reflectie |
| Transmission Weight | Bijdrage van lichttransmissie, bijvoorbeeld bij glas | 
| Coat Weight | Extra reflecterende deklaag, zoals lak |
| Coat Roughness | Ruwheid van de deklaag |
| Coat IOR | Brekingsindex van de deklaag |
| Coat Tint | Kleur van de deklaag |
| Coat Normal | Normaalrichting van de deklaag |
| Sheen Weight | Fluweelachtige of vezelige oppervlaktereflectie |
| Sheen Roughness | Ruwheid van de sheen-laag |
| Sheen Tint | Kleur van de sheen-laag |
| Emission Color | Kleur van het uitgestraalde licht |
| Emission Strength | Intensiteit van de emissie |
| Thin Film Thickness | Dikte van een dunne film voor interferentiekleuren |
| Thin Film IOR | Brekingsindex van de dunne film |
| Thin Wall | Behandelt het materiaal als een dunne wand in plaats van een gesloten volume |
